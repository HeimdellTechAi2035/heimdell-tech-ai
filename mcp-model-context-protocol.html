Model Context Protocol (MCP) servers

Let AI assistants use your systems safely, with permissions you control

Quick answer: The Model Context Protocol (MCP) is an open standard, introduced by Anthropic in late 2024, for connecting AI assistants to tools and data. In December 2025 Anthropic donated MCP to the Agentic AI Foundation, a Linux Foundation fund co-founded by Anthropic, Block and OpenAI. An MCP server lets assistants such as Claude, ChatGPT and Gemini use your booking system, product data or knowledge base in a controlled way.

Why it matters

An AI assistant that can only read your website can only guess. An assistant connected to your real systems can check live availability, look up an order or answer from your own approved knowledge. MCP is now the common way to make that connection, supported by the major assistants.

The risk is giving an AI too much access. A well-designed MCP server exposes only the specific things you choose, with the permissions, approval steps and logging you decide.

What we build

  • A scoped MCP server: a small set of clearly named tools, for example “check opening hours”, “get a quote” or “look up a product”, connected to your existing systems.
  • Read-only by default: actions that change anything, such as bookings or orders, are added deliberately and can require human approval.
  • Authentication and permissions: who can connect, what each connection may do, and rate limits.
  • Logging and monitoring: a record of every request, so you can see exactly what assistants did.
  • Documentation and testing: so you can see it working with real assistants before it goes live.

MCP, A2A and AP2: how they fit together

MCP connects an AI assistant to tools and data. A2A connects AI agents to each other, so a customer’s agent can talk to your business’s agent. AP2 covers how an agent is authorised to pay. Most businesses need only one or two of these, and we will say which.

Sources: Model Context Protocol blog: MCP joins the Agentic AI Foundation. These standards are still evolving, so we check the current specification before we build.

Frequently asked questions

What is the Model Context Protocol (MCP)?

MCP is an open standard for connecting AI assistants to tools and data. Anthropic introduced it in late 2024 and donated it to the Agentic AI Foundation, under the Linux Foundation, in December 2025.

How is MCP different from A2A?

MCP connects an AI assistant to tools and data, such as your booking system. A2A connects AI agents to each other, so one agent can hand a task to another. They solve different problems and are often used together.

Is it safe to let an AI assistant use my systems?

It can be, if the connection is designed carefully. We expose only the specific tools you choose, keep them read-only unless you decide otherwise, require approval for anything that changes data, and log every request.

Do I need an MCP server?

Not every business does. If you have live information that customers regularly ask AI assistants about, such as availability, stock or prices, it is worth considering. We will tell you honestly if accurate website data is enough for now.
